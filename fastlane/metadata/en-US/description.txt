Capture thoughts on Apple Watch and iPhone and keep them as Markdown daily notes.

Tap the watch microphone to record, or use system dictation and keyboard input. On the default phone route, iPhone transcribes audio, expands your verbal macros and appends captures to dated Markdown files in iCloud Drive or a folder you choose. Open those files with Obsidian, Logseq or another Markdown app.

Direct Send in version 1.1
After setup on iPhone, send watch text directly to a GitHub repository, an HTTPS webhook, or both. Your watch needs a network connection, but the phone does not need to be nearby. GitHub delivery runs while MacroMark is open on the watch. Direct Send preserves the captured text without expanding macros. Audio recordings always use the phone transcription route.

Check pending deliveries on the watch. Read replies that your own automation writes to GitHub reply files, with cached replies available offline. The Replies and deliveries complication opens the watch reply view. GitHub requires repository access, and webhooks require an endpoint you configure. MacroMark does not provide a bot or webhook service.

Capture and review
- Append captures to daily Markdown files with the original capture timestamp
- Keep watch captures queued until delivery is confirmed
- Use built-in and custom verbal macros on the phone route for Markdown formatting and reusable text
- Review daily notes by date on iPhone and Apple Watch
- See export status and retry notes that need attention
- Use capture and daily-log actions in Shortcuts
- Choose timestamp formatting, separators and an export folder

MacroMark is free. Capture, daily notes, custom macros, default-macro editing, folder settings and Direct Send do not require a purchase.

No MacroMark account is needed. Apple speech recognition availability depends on device, language and network support. Optional Direct Send sends text to the providers you choose; their privacy policies apply.
